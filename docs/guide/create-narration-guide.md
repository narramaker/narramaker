## 1. ナレーション作成の準備 {#section-1}

### 1.1 音声合成アプリの起動

Windowsデスクトップで操作します。  

1. 音声合成アプリの起動  
2. ウィンドウをピン止め
3. ウィンドウを最小化

### 1.2 音声合成の基本設定

PowerPoint の **NarraMaker タブ** で操作します。  

1. NarraMaker の**基本設定**を開く  
2. 音声合成エンジン を選択      
3. 音声合成モデル を選択 ... [変更]ボタン押下  
4. 必要に応じて話速などのパラメーターを変更  
5. **[保存]** を押下

!!! important "音声合成アプリをピン止めする理由"
    VOICEVOX 系音声合成アプリは、他のウィンドウの背面にいると処理性能が極端に落ちます。CPU/GPU の優先順位が落ちてしまうためです。それを回避するために、ウィンドウをピン止めして常に前面にあるようにします。なお、ピン止めした後であれば、ウィンドウを最小化しても性能は落ちないようです。

    音声合成の性能が落ちていると感じたときは、ウィンドウを前面に出して様子を見てみます。

!!! warning "基本設定の「保存」"
    設定内容をプレゼンテーションの中に埋め込みます。プレゼンテーションファイル自体は保存されません。

!!! note "話速などのパラメーター詳細"
    詳細は、音声合成アプリのヘルプで確認できます。NarraMaker では、各音声合成アプリに共通する一部の項目だけをサポートしています。

<summary>🔣 3.1 クローズドキャプションの長さ</summary>

### 🔣 3.1 クローズドキャプションの長さ

---

クローズドキャプションのテキストが長いと感じるときは、**[#ConcatSpeech]** を使って調整できます。また、**行中ポインター** を使用した場合もクローズドキャプションが調整されます。

#### 3.1.1 お勧めしない調整方法
クローズドキャプションの長さ調整は、１行の長さを適切に区切ることですが、単純に改行すると音声の読み上げ結果が不自然になることがあります。
```
音声合成アプリによっては、合成された音声の息継ぎやイントネーションに違いがあります。
　↓
音声合成アプリによっては、
合成された音声の
息継ぎや
イントネーションに
違いがあります。
```

#### 3.1.2 **[#ConcatSpeech]** の使用例
**[#ConcatSpeech]** ディレクティブで囲むと、クローズドキャプションは行単位で表示されますが、音声合成は１行の文として処理されます。
```
音声合成アプリによっては、合成された音声の息継ぎやイントネーションに違いがあります。
　↓
[#ConcatSpeech]
  音声合成アプリによっては、
  合成された音声の
  息継ぎや
  イントネーションに
  違いがあります。
[#EndConcatSpeech]
```

- 音声は一行の文として読み上げられます。
- クローズドキャプションは行単位で表示されます。  

⚠️ **[#ConcatSpeech]** には、いくつかの制約があります。[ディレクティブヘルプ](../help/directive-help.md)を参照してください。

---

#### 3.1.3 行中ポインターの使用例

```
音声合成アプリによっては、合成された音声の息継ぎやイントネーションに違いがあります。
　↓
合成された音声の[#P]息継ぎや[#P]イントネーションは、[#P]音声合成アプリによって[#P]違いがあります。
```
[#P]はモーションポインターのディレクティブで、行の途中にいれた[#P]を行中ポインターと呼びます。行中ポインターはクローズドキャプションの区切りになります。

### 🔣 3.2 読点「、」の調整

<summary>🔣 3.3 単語を列挙する際の読点「、」</summary>

### 🔣 3.3 単語を列挙する際の読点「、」

---

「赤、青、黄色」のように単語を列挙する文は、読点「、」や中点「・」が多くなりがちです。音声合成アプリで生成した音声は、もたついた印象を与えることがあります。

対策としては、最初の読点「、」や中点「・」を、「や」「または」などの接続詞に置き換えます。列挙が長いときは、最後に「そして」等をつけると列挙が終わる感覚が生まれます。   

目で読みやすい文章と、音声に変換しやすい文章は少し違いがありますので、以下の例を参考になさってください。

#### 3.3.1 ３つ以上の列挙 (並列)

```text
選択肢は 赤、青、緑、白、黒 です。
　↓
選択肢は 赤や青、緑、白、黒 です。
選択肢は 赤や青、緑、白、そして黒 です。
選択肢は 赤や青、緑、白、あるいは黒 です。
```

#### 3.3.2 ３つ以上の列挙 (直列)

```text
当社は、設計・施工・管理・アフターフォロー まで責任を持って...
　↓
当社は、設計から施工、管理、アフターフォロー まで責任を持って...
```

#### 3.3.3 ２つの列挙 (並列)

```text
選択肢は 白・黒 です。
　↓
選択肢は 白か黒 です。
選択肢は 白または黒 です。
```

#### 3.3.4 ２つの列挙 (直列)

```text
調整・視聴を繰り返して着地させましょう。
　↓
調整と視聴を繰り返して着地させましょう。
十中八九、調整および視聴の繰り返しになります😓。
```

### 🔣 3.4 音声の変更

---

```
[#Engine]
[#Speaker]
基本設定で指定したデフォルトのエンジンと音声に戻します。

```

<summary>🔣 3.6 無音時間の調整</summary>

### 🔣 3.6 無音時間の調整

---

文と文のつなぎがせわしなく感じたり、息継ぎが無いように聞こえる場合は、読み上げ前後の無音時間を調整してみます。  

#### 3.6.1 **[#PreGap][#PostGap]**

スライドの中だけで無音時間を指定します。発表者ノートが終わるまで、またはデフォルトに戻すまで有効です。
プレゼンテーション全体で無音時間を調整する場合は、基本設定を使います。
```
[#PreGap:0.5]
発話の前に0.5秒の無音時間ができます。

[#PostGap:0.5]
さらに、発話の後に0.5秒の無音時間ができます。

[#PreGap] [#PostGap]  
基本設定で指定したデフォルトに戻ります。
```

#### 3.6.2 **[#Quiet]**

その場だけの無音時間です。特定の部分で少し 間 を持たせたい時に有用です。
```
私は絶句しました。
[#Quiet:3]
とにかく絶句したのです。
```

### 4.1 クローズドキャプションで音声とは別な事を言う {#section-4-1}

用途がかなり限定的ですが、宣伝・告知系、寸劇ムービーなどに利用できます。

**例1**

読み仮名指定の `{表示テキスト|読み仮名}` 構文を使い、表示テキストに音声とは異なる内容を指定します。以下の例では、クローズドキャプションに「そろそろ帰れ」と表示されます。

```text
{そろそろ帰れ|その時計さん、仕事がはかどってますなあ。}
```

**例2**

視覚的に訴える注意喚起の例です。重要なことを、耳には丁寧に説明したうえで、視覚的には端的に伝えます。

```text
{⛔⛔⛔ よく考えて！ ⛔⛔⛔|このボタンを押すと元に戻れなくなるので、よく考えて決めてください。}
```


!!! tip "読み仮名構文「{表示テキスト|読み仮名}」"
    読み仮名部分には、カタカナ・ひらがな以外に、漢字が入った普通のテキストも指定できます。クローズドキャプションの表示テキストと音声合成用のテキストを別々に指定する機能を応用した小技です。

### 4.2 音声を反響させる（リバーブ/エコー） {#section-4-2}

用途がかなり限定的ですが、宣伝・告知系、寸劇ムービーなどに利用できます。

**例1：リバーブ（残響）**

**[#Speech]** ディレクティブで **With** と遅延パラメーターを使い、同じテキストを少し時間をずらして読み上げます。

```text
西暦2025年、そう遠くない未来
[#Speech:西暦2025年、そう遠くない未来:0.02::With]
```

**例2：エコー（反響）**

**[#Speech]** と **[#Volume]** ディレクティブを使い、声を小さくしながら徐々に時間をずらします。

```text
終わってた！
[#Volume:0.3]  [#Speech:終わってた！:0.2::With]
[#Volume:0.2]  [#Speech:終わってた！:0.6::With]
[#Volume:0.1]  [#Speech:終わってた！:1.2::With]
[#Volume:0.05] [#Speech:終わってた！:2::With]
[#Volume]
```

**例3：例1・2を組み合わせた寸劇**

```text
[#Speaker:阿井田 茂:ノーマル]
[#Speed:.9]
西暦2025年、そう遠くない未来
[#Speech:西暦2025年、そう遠くない未来:0.02::With]
[#Speed]

[#Speaker:morioki:ノーマル]
終わってた！
[#Volume:0.3]  [#Speech:終わってた！:0.2::With]
[#Volume:0.2]  [#Speech:終わってた！:0.6::With]
[#Volume:0.1]  [#Speech:終わってた！:1.2::With]
[#Volume:0.05] [#Speech:終わってた！:2::With]
[#Volume]
```

  
!!! note "調整のポイント"
    ずらし加減と音量調節がポイントです。

[🔼 4章 TOP](#section-4)

### 4.3 複数の人が同時に話す・話を被せる {#section-4-3}

用途がかなり限定的ですが、宣伝・告知系、寸劇ムービーなどに利用できます。

**例1：同時発話**

全員が同じことを同時に発話する、掛け声や唱和などのパターンです。**[#Speaker]** と **[#Speech]** で複数名の声を重ねて再生し、**[#Speed]** で話速を調整して同時に言い終えるようにします。

```text
[#Speaker:にせ:ノーマル]
[#Speed:1.3]
[#Speech:おはようございます!]
[#Speed]

[#Speaker:阿井田 茂:ノーマル]
[#Speech:おはようございます!:::With]

[#Speaker:水巻咲_T2モデル:ノーマル]
[#Speech:おはようございます!:::With]
```

**例2：話を被せる**

誰かが言い終える前に、別の声を重ねるパターンです。**[#Speaker]** と **[#Speech]** に **With** トリガーと遅延を指定して発話タイミングをずらします。

```text
[#Speaker:凛音エル:ノーマル]
おはようございます。
ご注文を伺います。

[#Speaker:にせ:ノーマル]
[#Speech:チューハイ！]

[#Speaker:阿井田 茂:ノーマル]
[#Speech:ちゅうなま一択:.5::With]

[#Speaker:水巻咲_T2モデル:ノーマル]
[#Speech:わたし赤ワイン:.8::With]

[#Quiet:1]
[#Speaker:凛音エル:ノーマル]
朝からアルコールですか...
お一人ずつお願いします...
```

**例3：ナレーションの並列進行**

**[#Speech]** は使わず、**[#Parallel]** ディレクティブで二つの発話進行を並列化します。

```text
[## 例にならないくらい手が込んだ例]

[#Cc:Off]
[#Parallel]
  [#Quiet:1]
  [#Speaker:にせ:ノーマル] [#Volume:.1]
  おねーさーん！
  チューハイおかわりー！
  あ、そうそう、チューハイ！
  てか、おねーさんどこ住んでんの？
  [#Volume:.3]
  あらー！めっちゃ塩対応！
  それより今日何時に上がんの？
  あ、ごめんなさーい、すいませんした!
[#EndParallel]
[#Volume]

[#Parallel]
  [#Speaker:水巻咲_T2モデル:ノーマル] ところで、寸劇以外思い浮かばないのよね...
  [#Speed:.7] [#Speaker:阿井田 茂:ノーマル] なーにが？
  [#Speed:.7] [#Speaker:水巻咲_T2モデル:ノーマル] {小技|こわざ}の使い道。
  [#Quiet:.5]
  [#Speed:.5]
  [#Speaker:阿井田 茂:ノーマル] [#Speech:あー、、、:::After]
  [#Speed] [#Speaker:水巻咲_T2モデル:ノーマル] 思いついたら教えて...
[#EndParallel]
[#Speed:.9]
[#Speaker:阿井田 茂:ノーマル] 何してんの...お前...

[## 作者より：本当に教えてください。使い道...]
```

!!! note "アイデア募集"
    寸劇以外の用途が思い浮かびません。他の用途があれば narramaker@gmail.com までご連絡いただけると幸いです。

## 5. 制約事項 {#section-5}
制作中または完成したプレゼンテーションファイルを、他の人と共有する場合、以下の点にご注意ください。 なお、PowerPoint for Mac はアニメーションの機能差が大きいため対象外です。

### 5.1 PowerPoint のエディションによる制約

✅ NarraMaker は Windows デスクトップアプリ専用です。  
🚫 PowerPoint Online、PowerPoint for Mac では使用できません。

| エディション | バージョン | 使用可否 |
| --- | --- | --- |
| Microsoft 365 版 | - | ✅制約なし（検証済み） |
| リテール版（市販） *1 | 2024 | ✅制約なし（⚠️未検証） *2 |
| 同上 | 2021 | ✅制約なし（NarraMaker 開発環境） |
| 同上 | 2019 | ✅制約なし（⚠️未検証） *2 |
| 同上 | 2016 | ✅制約なし（⚠️未検証） *2 |
| LTSC 版 *3 | - | 🚫動作しない可能性があります |

!!! note "エディションの補足"
    1. **リテール版**
       家電量販店・オンラインで購入する通常の Office、プリインストール、C2R（Click-to-Run）方式でインストールされる Office が該当します。

    2. **リテール版 2016、2019、2024**
       NarraMaker はリテール版 2016 以降の標準的な機能で開発されています。そのため、理論上は制約なく使用できますが、**実際の動作は検証されていません。**

    3. **LTSC 版（長期サービスチャネル）**
       企業・学校向けの長期サポートが受けられる買い切り版です。NarraMaker に必要な機能が含まれていません。

[🔼 5章 TOP](#section-5)

### 5.2 ファイルの保存場所による制約
NarraMaker は、プレゼンテーションファイルの保存場所に応じて、操作可否を判断しています。

| ファイルの保存場所 | 制約 |
| --- | --- |
| ローカルフォルダー | ✅制約なし |
| ネットワークフォルダー | ✅制約なし |
| OneDrive フォルダー | ✅制約なし、⚠️同時編集は非推奨 *1 |
| Teams / SharePoint | 🚫操作不可 *2 |

!!! note "保存場所の補足"
    1. ⚠️ **OneDrive でのリアルタイム同時編集は非推奨です**
       PowerPoint では、OneDrive 上のファイルに編集権限があれば複数名で同時編集できます。理論上は複数名で NarraMaker を使用できますが、未検証のため推奨しません。

    2. 🚫 **Teams / SharePoint 上のファイルには使用できません**
       これらの場所に保存されたプレゼンテーションでは、NarraMaker の操作を拒否します。編集履歴が自動作成され、フォルダーの容量を圧迫することがあるためです。

### 5.3 読み取り専用ファイルでの制約
読み取り専用のプレゼンテーションファイルでは、NarraMaker のほとんどの機能が使用できません。 一部の出力系機能は使用できます。  
以下に、操作可能な機能を示します。

| 機能 | 制約 |
| --- | --- |
| リボン **[プレビュー]** | ✅可能 |
| リボン **[動画出力]** | ✅可能 |
| リボン **[出力]** メニューからの各種出力 | ✅可能 |
| 上記以外 | 🚫使用不可 |

### 5.4 プレゼンテーションファイルの共有（NarraMaker なし環境）

制作したプレゼンテーションファイルを、NarraMaker および音声合成アプリが **《インストールされていない》** コンピューター上で扱う場合の制約です。  

#### 5.4.1 プレゼンテーションファイルの利用

| 他のコンピューターでの操作 | 可否 | 補足説明 |
| --- | --- | --- |
| 1. スライドショー | ✅完全に可能 | スライドショーに必要な情報・データはすべて共有されます。 |
| 2. 編集モードでの表示 | ✅完全に可能 | 問題ありません。編集は注意事項があります（5.4.2 を参照）。 |

#### 5.4.2 プレゼンテーションファイルの編集

プレゼンテーションファイルで、スライドショーや、NarraMaker での編集が予定されている場合の注意点です。
以下の点に注意していただければ、編集は問題ありません。

| 対象 | 詳細 | 操作 | 影響 |
| --- | --- | --- | --- |
| プレゼンテーションファイル | ユーザー設定プロパティ *1 | 🚫変更・削除 | NarraMaker での編集 |
| スライド | 発表者ノート | 🚫直接編集 | NarraMaker での編集
| | `#motion` 系ディレクティブで使用された図形・画像 *2 | 🚫位置・サイズの変更 | スライドショー |
| | スライド枠外の図形・画像 *2 | 🚫位置・サイズの変更 | スライドショー
| | 音声オブジェクト *3 | 🚫削除・トリミング | スライドショー
| | アニメーション *4 | 🚫変更・削除 | スライドショー

[🔼 5章 TOP](#section-5)

### 5.5 プレゼンテーションファイルの共有（NarraMaker あり環境）

制作したプレゼンテーションファイルを、NarraMaker および音声合成アプリが **《インストールされている》** コンピューター上で扱う場合の注意事項です。  制約・注意事項に絞って記載します。

!!! warning "5.5.1 音声合成モデル"
    音声を再生成する編集には、制作したコンピューターと同じ音声合成モデルが必要です。モデルがインストールされていない場合、NarraMaker は音声合成処理を中止します。

!!! warning "5.5.2 読み方・アクセントが辞書に依存した単語"
    辞書がない環境で音声合成を行うと、読み方とアクセントが変わる可能性があります。その場合は、制作したコンピューター上の「読み方＆アクセント辞書」が必要です。

!!! note "5.5.3 読み方＆アクセント辞書のエクスポート／インポート"
    読み方＆アクセント辞書は、音声合成アプリ上でエクスポート／インポートできます。
