# 動作環境

## 基本要件

NarraMaker は以下の環境での利用を想定しています。

| 項目 | 要件 |
|--------|--------|
| OS | Windows 11 |
| プレゼンテーションソフト | Microsoft PowerPoint |

## 音声合成ソフト

以下の音声合成ソフトで動作確認を行っています。

- AivisSpeech
- VOICEVOX
- ShareVOX

上記以外の音声合成ソフトについては、動作確認を行っていません。

## サポート方針

NarraMaker は個人開発のツールです。

企業向けソフトウェアのような動作保証は行っておらず、開発者の環境で動作確認できた内容をもとに提供しています。

異なる OS バージョン、PowerPoint のエディション、組織のセキュリティポリシー、端末設定などによっては、同じ結果にならない場合があります。

## PowerPoint について

NarraMaker は Microsoft PowerPoint を利用して動作します。

PowerPoint は永続ライセンス版、Microsoft 365 版、法人向け管理環境など複数の提供形態が存在し、それぞれ機能差や更新タイミングの違いがあります。

そのため、開発者環境で確認できている機能であっても、すべての PowerPoint 環境で同一の動作を保証するものではありません。

問題が発生した場合は、PowerPoint のバージョンやエディションの違いが影響している可能性があります。

詳しくは [PowerPoint 互換性](compatibility.md) をご覧ください。
