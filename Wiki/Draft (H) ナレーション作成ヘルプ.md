# 1. 準備
## 1.1 音声合成アプリの起動・ピン止め
音声ナレーションを作成するためには、音声合成アプリが起動している必要があります。また、音声合成の処理性能が落ちないように音声合成アブリのウィンドウが前面に出ている必要があります。

1. 音声合成アプリを起動
2. 音声合成アプリのウィンドウを **ピン止め**（前面に設定）

3. ウィンドウサイズを調整（必要に応じて小さくする）

> [!IMPORTANT]  
> - VOICEVOX系音声合成アブリは、他のウィンドウの背面にいるとCPU/GPUを優先的に使用できず、合成処理の性能が落ちてしまいます。

> [!NOTE]  
> - **■ ウィンドウを限りなく小さくしましょう ■**  
>   ウィンドウ枠を掴んで、ウィンドウサイズを限りなく小さくすることをお勧めします。  
> また、ピン止めした後は、ウィンドウを最小化しても性能が落ちないことが多いようです。

<br><br>

## 1.2 音声合成の基本設定

このプレゼンテーションファイルで、デフォルトで使用する **音声合成エンジン** や **音声合成モデル**、その他の調整項目を設定します。

1. NarraMaker の設定画面を開く（リボン [設定等] > [基本設定] ）
2. **音声合成エンジン** を選択      
3. **音声合成モデル** を選択 ... [変更]ボタン押下  
4. 話速などの調整項目を設定 (必要な場合)  

5. **[保存]** ボタン  

> [!WARNING]  
> - **[保存]** は、設定内容をプレゼンテーションの中に埋め込みます。プレゼンテーションファイルの保存は行いません。

> [!NOTE]  
> - 話速などの **調整項目** は、音声成合成アプリの設定項目を NarraMaker で入力できるようにしているものです。調整項目の説明は、音声合成アプリのヘルプで確認できます。  

<br><br>

# 2. 作成
## 2.1 読み上げるテキストの入力
1. スライドノートエディターを開く ... リボンの **[スライドノート編集]** を押下

2. 読み上げたい文章を入力する
3. **[保存]** ボタン

> [!WARNING]  
> - **[保存]** は、テキストをスライドノートに埋め込みます。プレゼンテーションファイルの保存は行いません。

> [!NOTE]  
> - **[生成]** ボタンを押すと、保存とアニメーション生成が同時に実行されます。  
> - 右上の **[+] [-]** ボタンで文字サイスを変更できます。

## 2.2 音声合成の実行（アニメーション生成）
1. 音声生成ダイアログを開く ... リボン **[アニメーション生成]** を押下

2. 音声合成を開始する ... オレンジ色の **[生成する]** ボタンを押下  
  
3. 進捗を眺めながら終わるのを待つ

> [!NOTE]  
> スライドノート内のテキストが音声合成済みの場合は、｢NarraMaker 音声生成｣ダイアログは表示されません。

## 2.3 合成した音声の確認（プレビュー）
- リボンの **[プレビュー]** を押すと生成した音声が再生されます。
- この音声はShスライドショーでも同じように再生されます。

> [!WARNING]  
> - 音声合成したスライドは、自動進行のスライドになります。
>  手動振興のスライドにしたい場合は `[#clock]` ディレクティブを追加して生成します。

> [!TIP]  
> - **音声合成アプリの画面を使用する**  
>   次のような場合は **音声合成アプリ** の画面で音声合成と視聴を行うと効率的です。  
>   - 大きなテキストの一部分だけを繰り返し視聴・調整したい  
>   - 音声合成モデルや話速などの調整を色々試したい

# 3. 調整
## 3.1 自然な読み上げにするための工夫
合成された音声の息継ぎやイントネーションは、音声合成アプリによって違いがありますが、文章の書き方でも変わってきます。ここでは AivisSpeech を使った場合で説明します。
### (1) １行の文章を細切れにしない  
音声合成アプリは、与えられた文章からある程度の文脈を読み取り、抑揚やイントネーション、息継ぎを考慮します。そのため、同じ単語でも文章として読ませた場合と、単語だけを読ませた場合でイントネーションが変わることがあります。  
ですので、ある程度の長さを持った文章として読ませることで自然さが増します。  
- 自然になる例 (少し楽しそうに聞こえる)
  ```
  これから楽しい会議を始めます。
  ```
- 不自然になる例 (あまり楽しそうに聞こえない)
  ```
  これから楽しい会議を  
  始めます。
  ```

### (2) 行中ポインター・[#concat] の活用
上記では、ある程度の文章で与えることを推奨しましたが、説明中にアニメーションを動かすために、どうしても文章を区切らないといけないことがあります。その場合は、行中ポインター・[#concat] を活用します。  
- **行中ポインター** (例)  
  １行の文章として読まれ、ポインターは指定したタイミング動作します。
  ```  
  これから楽しい[#p]会議を[#p]始めます。
  ```
- **[#concat]** (例)  
  テキストは連結されて１行の文章として読まれます。 
  アニメーションは指定したタイミングで動作します。     
  ```  
  [#concat]
    これから楽しい
      [#show:楽しそうな図]
    会議を
      [#show:会議の図]
    始めます。
      [#show:始める感じの図]
  [#endConcat]
  ```  

### (3) 句読点の調整
- 句点「。」 ... 文章の終わりを示しますので、できるだけ指定しましょう。  
- 読点「、」 ... ほんの少し息継ぎのような間が入ります。
