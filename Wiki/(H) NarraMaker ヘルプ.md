# 🧭 ディレクティブ一覧

## 0. 基本構文

#### 記号の意味

```text
[     ]  角括弧の中はコメントです。
[#... ]  #を付けるとディレクティブを表します。
   :     パラメーターの区切り文字です。
<     >  必須パラメーター    / 実際に記述に <> は不要です。
(     )  省略可能パラメーター / 実際に記述に () は不要です。
```
#### 構文例

```text
こんにちは
[#speech:こんにちは]
[#show:図形名A:0.2:1.0:With]
[#se:効果音B::With]
[#motion:図形A:図形B:0.0:1.0:After:hideFrom::keepSize]
```

| 種類 | 概要 | 書式 |
|---|---|---|
| 行頭ポインター | テキストとポインターを 1 行で記述 | `[#p]テキスト` |
| 行中ポインター | 任意タイミングでポインター実行 | `テキスト[#p]テキスト[#p]テキスト…` |

# 🧩 パラメーター仕様

## 遅延（delay）
アニメーション開始までの待機時間。  
- **0〜59 秒**  
- **小数第 3 位まで指定可能**（例：`0.125`）

## 期間（duration）
アニメーションの再生時間。  
- **0〜59 秒**  
- **小数第 3 位まで指定可能**

## トリガー（trigger）
アニメーション開始条件。

| 値 | 意味 |
|---|---|
| `After` | 直前のアニメーション終了後に実行 |
| `With` | 直前の動作と同時に実行 |
| `Click` | ユーザークリックで実行 |
| 省略 | ディレクティブごとのデフォルト値 |

## 移動元オプション（#motion）
| オプション | 意味 |
|---|---|
| `hideFrom` | 非表示状態でアニメーション開始 |
| `keepFrom` | 終了時に非表示にしない |
| 省略 | 表示状態で開始し、終了時に非表示にする |

## 移動先オプション（#motion）
| オプション | 意味 |
|---|---|
| `hideTo` | 終了時に非表示にする |
| 省略 | 非表示にしない |

## サイズオプション
| オプション | 意味 |
|---|---|
| `keepSize` | サイズを変更しない |
| 省略 | サイズを変更する |

## 方向（#slideIn / #slideOut）
| 値 | 意味 |
|---|---|
| `Left` | 左方向 |
| `Right` | 右方向 |
| `Up` | 上方向 |
| `Down` | 下方向 |
