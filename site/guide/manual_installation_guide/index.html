概要

NarraMaker を手動で PowerPoint にインストールする手順です。

ステップ

  1. Addins フォルダーへのコピー
  2. PowerPoint アドイン画面の表示
  3. PowerPoint へのアドイン登録

1. Addins フォルダーへのコピー

NarraMaker アドインファイル(.ppam)を、お使いのコンピューターの Addins フォルダーにコピーしてください。

  • コピーするファイル
    NarraMaker_{バージョン}.ppam    (Resourceフォルダー内にあります)

  • コピー先 (ユーザー毎のアドイン置き場です)
    %APPDATA%\Microsoft\AddIns


2. PowerPoint アドイン画面の表示

PowerPoint を起動して以下の順にクリックして行ってください。

  1. メニューの [ファイル]
  2. [その他]
  3. [オプション] ⇒ オプション画面が開く
  4. 左メニューの [アドイン]
  5. [管理] のプルダウン項目で PowerPointアドイン を選択
  6. [設定] をクリック ⇒ アドイン画面が開く

3. PowerPoint へのアドイン登録

  1. [新規追加] を押下 → ファイルダイアログが表示される
  2. NarraMaker_{最新バージョン}.ppam を選択
  3. [開く] を押下 → 登録完了
  4. [閉じる] を押下
