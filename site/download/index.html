NarraMaker ダウンロード

NarraMaker 2.7.0 リリース概要

主要トピック

  1. 画像切り抜き機能の新規搭載
  2. #Move ディレクティブ追加
  3. #Anim の制限撤廃によるアニメーション自由度向上
  4. Smooth／Bounce／強調効果による演出表現強化
  5. バージョンチェック機能追加

機能追加

1. #Move ディレクティブを追加

シェイプ移動専用の新ディレクティブ #Move を追加しました。

2. 画像切り抜き機能を追加

PowerPoint の MergeShapes を利用した画像切り抜き機能を実装しました。

主な対応内容

  • 任意形状による切り抜き
  • 型抜き切り抜き
  • 元画像シルエット維持
  • 切り抜き指示ダイアログ
  • 切り抜き後画像保持オプション

3. #Anim の制限緩和

従来は排他的だった #Anim を見直し、

  • #Show
  • #Hide
  • #Motion
  • #Anim

を同一シェイプ上で併用可能にしました。

これにより、表示・移動・自由アニメーションを柔軟に組み合わせられます。

4. モーション系 Smooth オプション追加

以下のディレクティブに Smooth オプションを追加しました。

  • #p
  • #Motion
  • #MotionIn
  • #MotionOut
  • #Move

移動の開始・終了を加速・減速させることで、より自然な移動表現を実現します。

さらに bounce を追加し、オーバーシュートを伴うアニメーションにも対応しました。

5. 表示系ディレクティブに強調オプション追加

以下のディレクティブで強調演出を指定可能になりました。

対象ディレクティブ
  • #Show
  • #SlideIn
  • #p
  • #Motion
  • #MotionIn
  • #Move
追加された強調効果
  • Pulse
  • ColorPulse
  • Seesaw
  • Spin
  • Wave

6. バージョンチェック機能追加

GitHub 上のバージョン情報と比較し、新バージョンを通知する機能を追加しました。

機能強化・改善

UI・操作性

  • 作業ウィンドウをリボンメニュー化

    • 書式
    • オブジェクト一覧
    • アニメーションウィンドウを個別に開けるよう改善

  • ポインターメニュー名称を見直し

    • オーバーレイ → 半透明
    • グロー → 光彩

  • 画像切り抜き画面の初期設定を見直し

    • 各オプションをデフォルト OFF 化

画像切り抜き機能の品質向上

  • MergeShapes ベースへ全面移行
  • 角度付き画像のキャッシュ化による性能改善
  • キャンバスサイズ・配置ロジックの改善
  • 処理時間の長い操作で進行ダイアログ表示
  • 軽量ケースでは高速処理経路を利用
  • 画質劣化を防ぐため AddPicture 方式を廃止し PasteSpecial(PNG) 方式へ変更

アニメーション関連

  • Smooth の演出品質を調整
  • Smooth 時の拡大縮小タイミングを改善
  • モーション系の解釈処理を共通化

内部改善

  • FreeAnim 実装開始
  • 古い Debug.Print を整理・除去
  • 各種コード整理・リファクタリング

不具合修正

アニメーション

  • FreeAnim と Motion 系を組み合わせた際、一部効果が CreatorList に登録されない問題を修正

ポインター機能

  • ポインター追加・解除を繰り返した際、重複したポインター番号が発生し Collection 登録エラーとなる場合がある問題を修正
  • ポインター解除時に連番を再採番するよう改善

構文解析

  • ディレクティブ前後の空白を許容するよう修正

字幕・Zオーダー

  • CC_BACKGROUND が意図せず大幅に背面へ移動する問題を修正
  • 字幕シェイプの前面化処理が機能していなかった問題を修正

画像切り抜き

  • スケーリング計算ミスにより切り抜きできないケースを修正
  • 型抜き画像が極端に縮小される問題を修正
  • 最終仕上げ時の画像保持処理を修正
  • 拡大縮小時の不具合を修正

バグ・考慮漏れ修正

  • 非常に長い文章(※)で音声生成時のエラーを修正。(PowerPointオブジェクト名の限界を超える文字数)
  • PowerPoint UIでメディアを圧縮後でアニメ生成すると、#ConcatSpeech に遅延が出る現象を改善。
  • 読み取り専用ファイルでの操作制限を追加。
  • 未保存の新規プレゼンテーションで動画等をエクスポートできないよう制限を追加。
  • voicevox, sharevox のスペルミスを修正。
  • 基本設定ダイアログのスペルミスを修正。

機能改善

  • グローフレーム(光彩)ポインターをマウスで掴みやすく変更。 (塗りつぶしなし → 透明な塗りつぶし)
  • 作業ウィンドウオープンは、書式ウィンドウをが先頭に来るように変更。
  • FitWindow の動作を改善。
  • #Quiet の動作改善。#Quiet直後は音声だけでなく、アニメーション(#Show等)も待機するよう変更。
  • フェード効果でスライドをめくる際に、#Motionを使用した図形の初期表示が不自然になるのを改善。

インストール方法

  • NarraMaker_バージョン.zip をダウンロードします。 (Source code ... は不要)
  • ダウンロードしたファイルを解凍した後、setup.bat を起動します。
  • セキュリティー警告が出る場合は、他のフォルダーにコピーしてお試しください。
  • PowerPoint画面が表示された後は、画面の案内に基づいて進めてください。

インストール後はダウンロードしたファイルを削除可能です。
