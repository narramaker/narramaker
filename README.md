# NarraMaker

NarraMaker は PowerPoint を用いたナレーション付きコンテンツ制作を支援するオープンソースアドインです。

PowerPoint 上でコンテンツ制作を行うクリエイターや教育用途を主な対象とし、ナレーション制作や動画コンテンツ作成の効率化を目的としています。

## 特徴

- PowerPoint アドインとして動作
- ナレーション制作を支援
- 動画コンテンツ制作を支援
- オープンソースソフトウェア
- 無償利用可能
